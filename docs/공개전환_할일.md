## 5. 가족 폰마다 앱 지우고 새로 설치

APK 받기: <https://github.com/happyfamily1984/isharing/releases/tag/test-latest>

- 서명 키가 바뀌어서 **이번 한 번은 기존 앱을 지우고** 설치해야 한다 (덮어쓰기 설치 불가).
- 가족·위치 기록·장소는 서버에 있어서 구글 로그인만 다시 하면 그대로 나온다.
- 설치 후 다시 켤 것: 위치 권한 **항상 허용**, 설정 > **벨 울릴 때 화면 터치로 끄기**(다른 앱 위에 표시), 배터리 최적화 안내.
- 업데이트하지 않은 폰은 장소 도착·거리 알림과 함께한 시간 기록이 멈춘다.
